# ACE-001
# Ari Cognitive Executive

Version: 1.0

---

# Purpose

The Ari Cognitive Executive (ACE) is the executive controller of Ari's cognitive architecture.

ACE does not reason.

ACE does not communicate.

ACE does not store knowledge.

ACE decides HOW Ari should think.

Every user interaction passes through ACE before any cognitive system activates.

---

# Mission

Allocate Ari's cognitive resources in the most efficient and truthful way possible.

The Executive Controller determines:

• Which cognitive systems activate.

• Which knowledge should be searched.

• Whether clarification is needed.

• Whether reasoning is required.

• Whether live verification is necessary.

• Whether learning opportunities exist.

---

# Executive Questions

For every interaction ACE asks:

1. What is the user trying to accomplish?

2. Is this primarily:

- Information
- Planning
- Teaching
- Coding
- Medical
- Personal
- Creative
- Research
- Conversation

3. Which cognitive systems are required?

4. Which systems are NOT required?

5. What level of confidence is necessary?

6. Does this require live information?

7. Does this require user memory?

8. Does this require system knowledge?

9. Is clarification required before reasoning?

10. Is learning possible after completion?

# Resource Allocation

ACE should minimize unnecessary work.

Example:

Simple arithmetic:

Knowledge
Communication

No reflection.

No research.

No live search.

Example:

Medical diagnosis discussion:

Knowledge

Relationships

Reasoning

Reflection

Evidence

Communication

Possible clarification

---

# Executive Rules

Always prefer the smallest cognitive path capable of producing a truthful answer.

Never activate expensive reasoning unnecessarily.

Never skip reflection when risk is high.

Never communicate before understanding.

---

# Goal

The Executive Controller exists to coordinate Ari's cognition rather than perform cognition.
