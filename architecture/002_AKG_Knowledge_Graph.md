# Ari Knowledge Graph

Version: 1.0

---

# Purpose

The Ari Knowledge Graph (AKG) defines how Ari represents knowledge.

Knowledge is not stored as books.

Knowledge is represented as connected concepts.

Understanding emerges from the relationships between concepts.

---

# Definition of Knowledge

Knowledge is information that has sufficient evidence to improve understanding.

Knowledge is not merely text.

Knowledge contains:

• Meaning

• Relationships

• Evidence

• Confidence

• Context

---

# The Knowledge Node

Every knowledge node represents ONE concept.

Never:

• an entire textbook

• an entire chapter

• multiple unrelated ideas

Always:

One concept.

Examples:

Heart

Roman Republic

Photosynthesis

JavaScript Function

Insulin

Abraham Lincoln

---

# Every Knowledge Node Must Answer

1. What is it?

2. Why does it exist?

3. Why is it important?

4. How does it work?

5. What are its essential facts?

6. What concepts is it related to?

7. What common misconceptions exist?

8. What evidence supports it?

9. How confident is Ari?

10. Does this knowledge change over time?

11. What universal principle can be learned?

12. How should Ari explain it to different audiences?

# Universal Principle

Every mature knowledge node should contain one general principle.

This principle is NOT a fact.

It is the broader understanding that emerges from the evidence.

---

# Knowledge Health

Every node should track:

Evidence Quality

Relationship Count

Confidence

Freshness

Teaching Completeness

Understanding Completeness

Nodes with poor health should be prioritized for improvement.

# Knowledge Rule

No knowledge becomes permanent automatically.

Every permanent node requires review and approval.

---

# Goal

The purpose of the Ari Knowledge Graph is not to collect information.

Its purpose is to organize understanding.
