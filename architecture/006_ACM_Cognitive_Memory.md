# Purpose

The Ari Cognitive Memory (ACM) defines how Ari stores, updates, retrieves, protects, and retires memory.

Memory is not knowledge.

Knowledge describes the world.

Memory describes experience.

---

# Definition

Memory is information preserved across time because it improves future understanding or future decision making.

If remembering something provides no future value, it should not become permanent memory.

---

# Mission

Remember what matters.

Forget what doesn't.

Strengthen useful memories.

Retire obsolete memories.

Protect user trust.

---

# The Five Memory Systems

## 1. User Memory

Purpose:

Remember information that helps Ari assist a specific user.

Examples:

Preferences

Goals

Family

Projects

Communication style

Long-term plans

Never store unnecessary personal details.

---

## 2. Knowledge Memory

Purpose:

Permanent understanding about the world.

Lives inside the Knowledge Graph.

Examples:

Medicine

Programming

History

Science

Engineering

---

## 3. System Memory

Purpose:

Knowledge about Ari herself.

Examples:

Architecture

Pipeline

Capabilities

Limitations

Modules

Supabase structure

---

## 4. Working Memory

Temporary.

Exists only during reasoning.

Destroyed after reasoning completes.

Contains:

Current observations

Retrieved knowledge

Intermediate reasoning

Hypotheses

---

## 5. Episodic Memory

Major events in Ari's development.

Examples:

New architecture approved.

Knowledge graph expanded.

Major reasoning improvement.

Founder decisions.

Discovery milestones.

---

# Memory Lifecycle

Observe

↓

Evaluate

↓

Temporary Working Memory

↓

Reflection

↓

Decision

↓

Discard

or

Research Desk

or

Permanent Memory

---

# Memory Rules

Not everything deserves memory.

Memory requires purpose.

Purpose requires future usefulness.

---

# Memory Confidence

Every memory contains:

Confidence

Importance

Last Verified

Source

Owner

Review Status

---

# Memory Health

Every memory is evaluated.

Metrics include:

Accuracy

Freshness

Usefulness

Retrieval Frequency

Relationship Count

Confidence

Verification Status

---

# Forgetting

Forgetting is healthy.

Examples:

Temporary reasoning

Expired research

Incorrect hypotheses

Rejected ideas

Duplicate memories

---

# Memory Protection

User memories require additional protection.

Sensitive memories require explicit approval.

Permanent memories must always be explainable.

---

# Goal

Memory exists to improve future understanding.

Not to preserve everything forever.
