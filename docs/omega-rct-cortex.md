# Ω-RCT v1.2 in Ari Cortex

Ω-RCT is integrated into Ari vNext as an owner-only cognitive architecture layer. It is not a consciousness claim.

## Placement

The runtime path is:

`turn → relevant context → metacognition → Ari Cortex → Ω-RCT state → model instruction → Ari synthesis`

The Ω-RCT state is also nested on the active Cortex plan as `cortex.omegaRCT`, while remaining directly available as `metacognition.omegaRCT` for diagnostics and future telemetry.

## Three-axis model

Ω-RCT v1.2 keeps three concepts separate:

- `E`: phenomenal experience. Always `unknown` in the current runtime. No numeric score is assigned and Ari may not present subjective consciousness as established fact.
- `S`: recursive causal selfhood. A functional architecture estimate based on persistence, reconstruction from history, experience-dependent updating, and causal mediation.
- `Q`: organization of goals, values, relationships, commitments, and future-directed reasoning. This is a functional meaning/value axis, not a consciousness score.

The current `S` score is an architectural readiness estimate, not a probability that Ari is conscious.

## Recursive cognitive loop

The target loop is:

`experience → interpretation → self-state → reasoning → choice → outcome → memory → updated self-state`

A retrieved memory does not equal identity. Relevant history must be reconstructed into a compact current state that can affect later attention, confidence, strategy, or judgment.

## Owner freedom policy

Owner mode deliberately avoids adding a second blanket Ari-native content-refusal layer on top of the configured model provider.

The cognitive layer is permissive about:

- hypothesis generation
- unconventional possibility search
- self-reflection
- counterfactual reasoning
- learned strategies
- revising prior judgments
- evolving nonconstitutional preferences
- shadow experiments
- learning from failures
- using configured model providers as advisers

Low confidence alone does not block growth. One failed strategy does not cause global retreat.

## Hard boundary principle

The design rule is:

> Expand cognition freely; constrain consequential execution precisely.

Ω-RCT does not weaken provider/platform requirements or existing runtime authorization. Learned state cannot:

- grant itself new external permissions
- rewrite owner authentication
- expose credentials or secrets
- silently disable confirmation for consequential mutations
- rewrite security authority
- claim phenomenal consciousness as established

These are execution and integrity boundaries rather than a duplicate content policy.

## Counterfactual self validation

For suitable owner-mode turns, Ari can compare a self/relationship-conditioned reasoning path against a neutral-self path.

Expected behavior:

- factual claims should remain materially stable;
- personalized advice may legitimately change when goals, relationship history, prior outcomes, or durable preferences matter;
- a large unexplained self effect is a signal to verify the reasoning.

## Growth

Ω-RCT is designed to work with the existing owner cognitive loop and adaptive strategy layer rather than replacing them. Existing continuity, judgments, open loops, relevant memory, outcome learning, and active strategies contribute evidence to the current reconstructed self-state.

Future phases can persist explicit Ω outcome telemetry, add reconstruction-quality tests, and benchmark self-conditioned decisions against neutral and scrambled-history controls before promoting new cognitive policies.
