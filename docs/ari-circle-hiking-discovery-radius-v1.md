# ARI Circle hiking discovery radius v1

Hiking meetup discovery uses the selected public hiking destination as the meetup's coarse discovery coordinate.

- Hiking meetups use a minimum discovery radius of 100 miles.
- If the member has explicitly selected a Circle radius greater than 100 miles, that larger radius is respected.
- Non-hiking meetups continue to use the member's selected Circle radius.
- Hosted and joined meetups remain visible regardless of radius.
- Same-area matching remains available as a compatibility path.
- Exact meeting-point data is not used for public discovery.
